Part 01 · Principle

What is the FieldTrip real-time buffer?

Think of the buffer as a shared mailbox between the acquisition system and one or more analysis programs. The acquisition side keeps adding new data; MATLAB checks the mailbox and reads the newest samples.

The three things that matter

Header

Describes the stream: number of channels, sampling rate, channel labels, and data format. Read this first.

Samples

The continuously arriving measurements. MATLAB reads blocks of samples and processes only what is new.

Events

Markers such as triggers or trial events. They help relate neural data to the experiment timeline.

Why use a buffer?

  • Acquisition and analysis can run as separate programs.
  • They can run on different computers connected over a network.
  • More than one client can read the same stream at the same time.
  • MATLAB can process short blocks while the buffer handles incoming data independently.

How the data move

MEGIN acquisition
The MEGIN system acquires the sensor signals and stores the recording in its normal raw-data format.
Bridge software
A MEGIN-specific interface reads the live data and forwards them to the FieldTrip buffer. In the documented legacy route this is neuromag2ft.
FieldTrip buffer
The buffer makes the stream available through a network connection, commonly port 1972.
MATLAB client
MATLAB reads the header, samples, and events using FieldTrip functions such as ft_read_header, ft_read_data, and ft_read_event.
Your analysis
Your code updates plots or calculates features from each new block.

What you need to know (and what you can ignore)

ConceptBeginner interpretationNeed now?
TCP/IP protocolThe common language used to send data between programs over the network.No. Understand host and port only.
HeaderStream metadata, including sampling rate and channels.Yes.
Sample indexA counter telling you how many samples have arrived.Yes. It helps detect new data and gaps.
EventA timestamped marker, such as a stimulus trigger.Yes, once you use task markers.
Binary protocol detailsHow data are encoded internally.No, unless debugging or writing a new client.
Key idea: the buffer is not itself a signal-processing algorithm. It transports data. Filtering, power estimation, phase estimation, and trigger decisions happen in your MATLAB code (or another client).

Buffer address

A typical local example is buffer://localhost:1972. If MATLAB runs on another computer, replace localhost with the acquisition computer's network name or IP address, and make sure the network allows access to the chosen port.

dataset = 'buffer://localhost:1972';
hdr = ft_read_header(dataset);
events = ft_read_event(dataset);

The MATLAB interface is built around FieldTrip's standard file-reading functions. The buffer protocol itself is language-independent, so a Python client can be added later without changing the basic data-flow concept.
