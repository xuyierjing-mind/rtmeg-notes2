# Reference maintenance

The HTML guide contains links to FieldTrip documentation and other external resources. This folder is a place to record sources as they are checked and used.

Before relying on a reference:

1. Open the link and confirm that it resolves.
2. Check that the page still describes the relevant FieldTrip release or MEGIN acquisition configuration.
3. Record the access date and, where possible, the software version.
4. Prefer official FieldTrip and MEGIN documentation for installation and compatibility claims.
5. Treat third-party examples and historical operator notes as context, not universal instructions.

No independent live-link or current-version verification is claimed for this initial packaged release.
