Real-time MEG processing with MEGIN + FieldTrip

A step-by-step notebook for getting data out of the MEGIN acquisition system, reading it safely in MATLAB, monitoring useful signal features, and eventually building a validated closed-loop experiment.

1. ConnectivityMATLAB reads the buffer header and new data.Correct sampling rate, channel count, and steadily increasing sample count.
2. MonitoringPlot a few channels and inspect events.No unexplained gaps, frozen stream, or channel mix-up.
3. Online featuresCalculate rolling RMS / band power / frequency.Online results agree with offline analysis within a defined tolerance.
4. Timing validationMeasure data and output delays with recorded signals.Mean, spread, and outliers are quantified.
5. Closed loopTrigger a harmless test output at a predicted phase or condition.Independent offline verification confirms actual onset timing.

Important MEGIN compatibility note

Do not assume every MEGIN installation uses the same bridge. FieldTrip's current Neuromag page notes issues with neuromag2ft on some TRIUX neo systems after DACQ software changes, and recommends an LSL-based interface for those configurations. Your local operator manual documents a legacy neuromag2ft workflow. Treat that as installation-specific and confirm the exact system model, DACQ version, bridge binary, and local support status before relying on it.
